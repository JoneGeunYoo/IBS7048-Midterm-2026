# IBS7048-Midterm-2026
Code and results for the IBS7048 Metagenomics Midterm Exam (2026)

This repository contains the R and Bash scripts and their outputs for Problems 1–6.

## Requirements

- Bash (Linux, macOS, or WSL on Windows)
- R
- R packages for Problem 4: dada2, DECIPHER, Biostrings, phangorn, ape

If the packages for Problem 4 are not installed, run the following commands in R:

```r
install.packages(c("BiocManager", "phangorn", "ape"))
BiocManager::install(c("dada2", "DECIPHER", "Biostrings"),
                     ask = FALSE, update = FALSE)
```

Additional system dependencies may be required on Linux.

## How to Run

Download or clone this repository and open a Bash terminal in the repository root directory.

### Problems 1–2: FASTQ File Organization
  
- Problem 1 generates 40 dummy FASTQ files and organizes them into directories using Bash.
- Problem 2 organizes the same files using R and compares the results.

Run the following commands in order:

```bash
bash "Problem 1/problem1_complete.sh"
cd IBS7048_2026
Rscript "../Problem 2/problem2_complete.R"
cd ..
```

- The scripts generate raw/, sorted_bash/, and sorted_R/ inside IBS7048_2026/.

- Expected results: 40 FASTQ files in each of `raw/`, `sorted_bash/`, and `sorted_R/`, with 10 files per condition/read-direction subdirectory and matching filenames between the Bash and R outputs.

### Problem 3: Sequencing Platform Comparison

```bash
Rscript "Problem 3/problem3_complete.R"
```

- This script calculates the total microbial sequencing yield for each platform under a budget of USD 600.

### Problem 4: DADA2 and Phylogenetic Analysis

```bash
Rscript "Problem 4/problem4_complete.R" > "Problem 4/problem4_output.txt" 2>&1
```

- This script performs read filtering, denoising, merging, chimera removal, ASV abundance analysis, and Neighbor-Joining tree construction.

- It uses example FASTQ files from the dada2 package.

### Problem 5: Host Depletion Analysis

```bash
Rscript "Problem 5/problem5_complete.R"
```

- This script calculates microbial reads, reads remaining after excluding Taxon_X, and treated/untreated fold changes.

### Problem 6: Microbiome Score Analysis

```bash
Rscript "Problem 6/problem6_complete.R"
```

- This script calculates the odds ratio, 95% confidence interval, CASI difference, and probability corresponding to a microbiome score change.

## Outputs

Problems 1–3 and 5–6: problemN_output.txt

Problem 4: problem4_output.txt, CSV tables, PNG figures, and a Newick tree file
